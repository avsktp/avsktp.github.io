# KRISTIAN ṬHALAI PAWL (KṬP)
## Armed Veng South Branch - Member Directory & Notice Board
*Motto: "Rawngbawl tura chhandam" (Ephesi 2:10)*  
*Armed Veng Bial • Mizoram Presbyterian Kohhran*

---

A clean, bright **Light Theme** Web Application designed specifically for **Kristian Ṭhalai Pawl (KṬP), Armed Veng South Branch**.

---

## 👥 Groups
The branch members are organized strictly into 3 groups:
1. 🔴 **Sadrak**
2. 🟢 **Mesak**
3. 🔵 **Abednego**

---

## 📋 Directory Columns
* **#** (Serial Number)
* **Member Name & Photo** (Passport Size Photo / Selfie converted to ultra-light WebP format, with initials avatar fallback)
* **Group** (Sadrak, Mesak, Abednego)
* **H/No. & Upa Bial** (In Number e.g. H-14, and Elder Section e.g. Upa Bial 1–8)
* **Contact** (10-digit mobile number with 1-click **WhatsApp** chat, direct **Phone Call**, **Save to Phone Contacts (vCard)**, and **Copy Number** buttons)
* **Actions** (Visible only when Branch Secretary is logged in)

---

## 📸 Self-Registration (Branch Members Add Themselves)
* Any branch member can add themselves by clicking **"In-ziak lut rawh (+ Add Yourself)"** at the top right.
* Members can fill in:
  * Full Name
  * Group (Sadrak / Mesak / Abednego)
  * 10-digit Contact Number
  * Gender (Mipa / Hmeichhia)
  * House Number (H/No.)
  * Upa Bial (Upa Bial 1 – 8)
  * **Selfie Camera / Passport Photo Upload**:
    * Automatically center-crops to passport proportions (300 × 350).
    * Automatically compresses into **WebP format (~15 KB)** to minimize storage footprint.
* Public members **cannot** edit or delete other members or manage notices.

---

## 📢 Notice Board (Hriattirna)
* Accessible anytime via the **"Notice Board"** tab at the top.
* Categories:
  * 🟢 **Inkhawm** (Weekly fellowship, preaching & leadership programs)
  * 🟡 **Hnatlang** (Church cleaning, community work camps)
  * 🟣 **Zaipawl** (Choir practice, singing programs)
  * 🔵 **General** (General branch announcements)
* **1-Click WhatsApp Share**: Formats the notice automatically with church headers, date, category, and motto ready to broadcast to WhatsApp groups.
* Managed exclusively by the **Branch Secretary**.

---

## 🔒 Branch Secretary Administrative Access
* Click **"Secretary Login"** in the top right.
* Enter the Secretary password: **`avsktp`**
* Once logged in, the Secretary can:
  * Edit any member record (Name, Group, Contact, Photo, H/No., Upa Bial).
  * Delete member records with confirmation.
  * Post, edit, and delete announcements on the Notice Board.
  * Change the Secretary password at any time.
  * Import or restore JSON/CSV backups.
* Click **"Log out"** anytime to return to public view.

## 🌐 Next Step on GitHub Pages (Live 24/7)
After turning on GitHub Pages under **Settings -> Pages** (Branch: `main`, Folder: `/` root, Click Save):
1. Wait **30 to 60 seconds** for GitHub Actions to build the site.
2. Refresh the **Settings -> Pages** page.
3. At the top of the Pages section, you will see a green box:
   > **"Your site is live at https://<your-username>.github.io/ktp-member/"**
4. Click **Visit site** or copy that URL!
5. Send that link to your Branch members, WhatsApp groups, and leaders. It will open on any phone, Android, iPhone, tablet, laptop, or PC 24 hours a day, 7 days a week!
